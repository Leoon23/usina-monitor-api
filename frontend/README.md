# Monitor da Usina - Frontend

Interface web para monitorar telemetria em tempo real, com alerta crítico e histórico.

## O que faz
- Mostra status atual: potência, tensão e corrente
- Badge NORMAL / CRITICO em tempo real
- Histórico de alertas com data e hora
- Atualização automática a cada 3 segundos

## Tecnologias
React + TypeScript + Vite + CSS

## Como rodar

Backend (em outro terminal):
```bash
cd ..
npm run dev
